## 1.1.2. 한눈에보는문화정보 조회서비스 흐름

**<< 기본흐름 >>**

1. 사용자시스템은 문화캘린더정보목록조회 오퍼레이션을 요청한다.
   1. 조회조건에 해당하는 자료가 없을 경우
      1. '조회된 내용이 없습니다' 메시지를 출력한다.
      2. 조회조건을 변경하여 문화캘린더정보목록조회 오퍼레이션을 요청한다.

      2. 조회조건을 변경하여 지역별 문화정보목록조회 오퍼레이션을 요청한다.
